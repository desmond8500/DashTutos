# [Laravel 13](readme.md)

## Description

Encore une nouvelle version de laravel

## Installation avec Laravel installer

```console
composer global require laravel/installer
```

```console
laravel new example-app
```

```console
cd example-app
npm install && npm run build
composer run dev
``` 

## Ajouter des routes API

Par défaut les routes API sont désactivés. 

```console
php artisan install:api
```
