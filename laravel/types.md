# [Types](readme.md)

## Types scalaires (valeurs simples)

- bool : Un booléen qui accepte uniquement les valeurs true ou false.
- int : Un nombre entier (positif ou négatif), tel que 42.
- float : Un nombre à virgule flottante (ou nombre décimal), tel que 3.14.
- string : Une chaîne de caractères, telle que "Bonjour"

## Types composés (valeurs multiples)

- array : Un tableau permettant de stocker une liste ordonnée de données ou des paires clé-valeur.
- object : Une instance de classe issue de la programmation orientée objet.
- callable : Une fonction ou une méthode qu'il est possible d'appeler dynamiquement.
- iterable : Un pseudo-type regroupant les tableaux et les objets implémentant l'interface Traversable

## Types spéciaux

- null : Une variable vide ou ne contenant aucune valeur.
- resource : Une référence vers une ressource externe (comme une connexion à une base de données ou un fichier ouvert)

## Nouveaux types et déclarations avancées

- mixed : Indique qu'une valeur peut appartenir à n'importe quel type.
- void / never : Utilisés pour les fonctions ne retournant aucune valeur ou ne s'arrêtant jamais normalement.
