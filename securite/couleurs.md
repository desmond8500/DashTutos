# [Couleurs](readme.md)

## Description

Code de couleurs à utiliser pour identifier les systèmes de sécurités, équipements, plans et cablage.

## Systèmes

| Système | Couleur | Code HEX |
|:---|:---|:---|
| Détection incendie | 🔴 Rouge | `#D32F2F` |
| Intrusion / Alarme | 🟠 Orange | `#F57C00` |
| Vidéosurveillance | 🔵 Bleu | `#1976D2` |
| Contrôle d'accès | 🟢 Vert | `#388E3C` |
| Réseau / Data | 🩵 Cyan | `#00ACC1` |
| Domotique / Automatisation | 🟡 Jaune | `#FBC02D` |
